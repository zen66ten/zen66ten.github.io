// Projects

redarmor is a TLS certificate expiry tracker, written in Go with zero dependencies. It dials a list of hosts, reads the served certificate, and classifies each one before expiry becomes an outage.

v1 ships as a one-shot CLI on the standard library alone. The check, classify, and report steps stay separate so the logic is testable without a network. A daemon and a Kubernetes operator reuse that same core in later stages.

k8s-lab is a local Kubernetes laboratory on KVM/QEMU VMs. A place to test bootstrap methods, CNIs, and networking patterns close to a real cluster, without leaving the host.

Each iteration swaps one piece of the stack (bootstrap tool, CNI, runtime) while the rest stays fixed, so results stay comparable. Current iteration: kubeadm, Cilium replacing kube-proxy, containerd, three VMs on libvirt.

NIX-Z is a hardware monitoring suite for Linux, in the spirit of HWiNFO64. It reads the kernel and vendor tools to inventory the whole machine and report every sensor live.

AI-assisted. I wanted an HWiNFO64 equivalent for Linux, so I leaned on generated code and worked through it as it grew. What started as a sensor reader is now a daemon, a TUI, a CLI client, and a Qt desktop app with alerts, logging, and Prometheus metrics.
